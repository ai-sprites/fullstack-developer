# 跨端质量检查

用足够的真实证据说明完整功能是否成立。本实践可独立使用，不依赖单端角色、其他实践或新测试平台。

- 联调、契约和回归范围：读 [完整路径检查](references/end-to-end.md)。
- 跨端授权、失败和恢复：读 [安全与失败](references/security-resilience.md)。

从本次验收和差异选择检查，使用项目已有工具。报告实际版本、环境、操作与结果，并明确 mock、静态检查和真实服务的边界。待定规则保留来源和影响，不用虚构期望替代确认；是否落盘按交接需要决定。
