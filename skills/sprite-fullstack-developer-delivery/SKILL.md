# 完整功能交付

从用户操作到服务结果组织当前改动，不要求安装前端或后端角色、其他 Skill 或完整 SDLC。以项目现有代码与约定为准，实践不预选技术。

- 用户路径、状态和两端契约：读 [功能与契约](references/slice-contract.md)。
- 跨仓库资料、协作和修改顺序：读 [协作与依据](references/coordination.md)。

先完成最小可用功能及必要验证。缺项列“待确定”，说明来源和只影响哪些部分；有价值的并行工作继续。交付可观察结果与实际证据，只有多步骤交接确实需要时保存计划。
